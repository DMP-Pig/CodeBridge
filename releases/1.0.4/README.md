## 1.0.4 更新内容

### 新增功能
1. **手动转发**：手机端新增「手动发送验证码」，输入任意验证码可立即推送到 PC（测试 / 补发）
2. **记录设备名**：PC 接收入口记录发送设备的名称与 ID，历史中可区分是哪台手机发送
3. **扫码配对增强**：PC 二维码携带主机名，扫码后自动作为该 PC 配置的名称
4. **常驻通知显示最新验证码**：手机常驻服务通知 / 锁屏卡片显示最近一条验证码（可在设置中关闭）
5. **统计导出 CSV**：PC 端周报 / 月报新增「导出报告 CSV」，保存为带统计汇总的 CSV 文件
6. **主题模式**：PC 与手机端支持「跟随系统 / 深色 / 浅色」，手机端默认跟随系统
7. **历史显示来源设备**：PC 端历史记录显示验证码来自哪台手机（设备名）
8. **开机自启默认关闭**：避免默认开机自启，用户可在设置中按需开启
9. **局域网设备白名单**（默认关闭，手机端是主导）：开启后只向白名单内的 PC 推送验证码，白名单支持 PC 名称或地址
10. **临时授权码配对**：PC 端一键生成 6 位授权码（30 秒有效），手机端输入授权码后自动搜索局域网并完成配对

### 修复
- **修复：运营商短信不再误当验证码**：10086 / 10010 / 10000 等运营商、106 短信通道、95/96 银行服务号均被过滤；独立数字串必须同时出现「验证码 / 校验码 / 动态码 / 登录码」等上下文关键词才会被采纳
- **修复：只推送最新验证码**：同一来源同一验证码在 60 秒窗口内去重；短信应用把多条短信合并进同一通知时只取正文中最后（最新）一条验证码，旧通知未划走也不会把旧验证码重复推送
- 版本号：Android versionCode 13 / versionName 1.0.4
