# 构建指南

## PC 端（Windows / macOS / Linux）

```bash
cd pc-client
npm install
npm start        # 开发运行
npm run pack     # 生成未打包目录（electron-builder --dir）
npm run dist     # 生成安装包（nsis / dmg / AppImage+deb）
```

> 提示：国内网络可先设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再 `npm install`。

发布产物输出到 `pc-client/dist/`，按《通用文件管理要求》整理进 `releases/<版本号>/`。

### 防火墙

手机与 PC 需处于同一局域网；Windows 首次运行或改端口后，请在防火墙中放行对应端口（TCP）。

## 手机端 APK

用 Android Studio（Koala 或更新）打开 `android-app/`：

1. 等待 Gradle 同步（首次需联网下载依赖）。
2. 连接手机（开启 USB 调试）或使用模拟器。
3. 运行 `app` 模块，或 `Build → Build APK(s)` 生成 `app/build/outputs/apk/.../app-debug.apk`。
4. 安装后打开 App：填写 PC 局域网地址与 Token，开启「通知使用权」，按需授予短信权限。

> 若本机未安装 Android SDK，Android Studio 会提示安装；命令行环境需自行安装
> cmdline-tools + `platforms;android-35` + `build-tools;35.0.0` 并配置 `ANDROID_HOME`。

## 版本与发布

- 当前版本 `0.1.0beta1`：Beta / 迭代版本，仅本地保留，不上传远端。
- 正式版发布时：完整上传全部平台/全部类型资产，并核对清单（见《通用文件管理要求》）。
- 文件命名：`PhoneToPCCopyCode-<版本号>-<平台>-<类型>.扩展名`
