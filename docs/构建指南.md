# 构建指南

## PC 端（Windows / macOS / Linux）

```bash
cd pc-client
npm install
npm start        # 开发运行
npm run pack     # 生成未打包目录（electron-builder --dir）
npm run dist     # 生成安装包（nsis / dmg / AppImage+deb）
```

国内网络构建时设置镜像（本项目 Windows 版已用此方式实测打包成功）：

```bash
# PowerShell
$env:ELECTRON_MIRROR = "https://npmmirror.com/mirrors/electron/"
$env:ELECTRON_BUILDER_BINARIES_MIRROR = "https://npmmirror.com/mirrors/electron-builder-binaries/"
$env:CSC_IDENTITY_AUTO_DISCOVERY = "false"   # 跳过代码签名
npm run dist
```

注意：`package.json` 必须是 **UTF-8 无 BOM** 编码，否则 electron-builder 的 app-builder 无法解析。

发布产物输出到 `pc-client/dist/`，按《通用文件管理要求》归档到 `releases/<版本号>/`。

### 防火墙

手机与 PC 需处于同一局域网；Windows 首次运行或改端口后，请在防火墙中放行对应端口（TCP）。

## 手机端 APK（本机已实测构建成功）

### 方式一：Android Studio

用 Android Studio 打开 `android-app/`，等待 Gradle 同步后 `Build → Build APK(s)`。

### 方式二：命令行（本机已验证）

依赖：
- JDK 17+（本机为 21）
- Android SDK（本机位于 `D:\Android`，含 platforms;android-36 与 build-tools;36.1.0），在 `android-app/local.properties` 配置 `sdk.dir`
- Gradle 8.8（本机缓存于 `~/.gradle/wrapper/dists/gradle-8.8-bin/...`）

```bash
cd android-app
# 使用本机缓存的 gradle.bat（或 gradlew）
gradle assembleDebug
```

产物：`android-app/app/build/outputs/apk/debug/app-debug.apk`。

依赖下载使用阿里云 Maven 镜像（已在 `settings.gradle.kts` 配置，国内网络可用）：

- `https://maven.aliyun.com/repository/google`
- `https://maven.aliyun.com/repository/central`
- `https://maven.aliyun.com/repository/gradle-plugin`

### 安装与权限

1. 手机与 PC 同一局域网。
2. 安装 APK 后打开 App：填写 PC 局域网地址与 Token。
3. 开启「通知使用权」（读取短信验证码通知）；按需授予短信权限（备用通道）。
