# 局域网通信协议

## 概述

手机端 → PC 端，使用 HTTP JSON，UTF-8 编码。PC 端默认监听 `0.0.0.0:9841`。

## 发送验证码

```
POST /api/code
Content-Type: application/json
X-P2P-Token: <可选，与 PC 设置一致>
```

请求体：

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `code` | 是 | string | 验证码内容 |
| `app` | 否 | string | 来源应用（短信/微信/银行…） |
| `source` | 否 | string | 来源号码/账号 |
| `token` | 否 | string | 与请求头等价，二选一 |

响应：

```json
{ "ok": true, "id": "da3968f5-..." }
```

错误：

| HTTP | 含义 |
|---|---|
| 400 | 缺少 `code` 或 JSON 非法 |
| 401 | Token 不匹配 |
| 404 | 路径不存在 |

## 健康检查

```
GET /health
→ { "ok": true, "name": "PhoneToPCCopyCode", "version": "1.0.0-beta.1" }
```

## CORS

所有响应携带 `Access-Control-Allow-Origin: *`，支持浏览器调试。
