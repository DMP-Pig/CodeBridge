# 架构说明

## 系统组成

```
┌─────────────┐   局域网 HTTP    ┌──────────────────┐   本机 HTTP     ┌──────────────┐
│  手机 (APK) │ ───────────────► │  PC 客户端        │ ─────────────► │  WinIsland   │
│  短信验证码   │  POST /api/code  │  展示 / 复制 / 上岛 │  POST /v1/island │  灵动岛卡片   │
└─────────────┘                  └──────────────────┘                 └──────────────┘
```

- **手机端**（`android-app/`）：监听短信验证码通知（NotificationListenerService，无需成为默认短信应用；
  另有 RECEIVE_SMS 广播备用通道），用正则提取验证码，通过局域网 HTTP 发送到 PC。
- **PC 端**（`pc-client/`）：Electron 应用，内置局域网 HTTP 服务，收到验证码后：
  - 展示：液态玻璃风格大卡 + 悬浮提示 + 历史记录
  - 上岛：调用 WinIsland 上岛 API（`http://127.0.0.1:9840`）推送灵动岛卡片
  - 复制：写入系统剪贴板（可自动 / 手动 / 通过灵动岛按钮触发）
- 所有行为（自动展示 / 自动复制 / 自动上岛 / 端口 / Token / 上岛时长等）均可在设置中配置。

## PC 端模块

| 文件 | 职责 |
|---|---|
| `src/main/main.js` | 主进程：HTTP 服务、设置持久化、剪贴板、上岛推送、托盘、窗口 |
| `src/main/preload.js` | contextBridge 安全桥接 |
| `src/renderer/index.html` | 界面结构 |
| `src/renderer/styles.css` | 液态玻璃主题、圆角、动画 |
| `src/renderer/app.js` | 渲染进程逻辑 |

## 手机端模块

| 文件 | 职责 |
|---|---|
| `service/SmsNotificationListener.kt` | 通知监听：读取短信验证码通知 |
| `service/SmsReceiver.kt` | 短信广播备用通道 |
| `data/CodeExtractor.kt` | 验证码提取（自定义正则 + 内置中文句式 + 回退） |
| `data/CodeSender.kt` | 局域网 HTTP 发送 |
| `data/Settings.kt` | SharedPreferences 设置 |
| `ui/MainScreen.kt` | Compose 液态玻璃界面 |

## 技术选型

- PC 端：Electron（Windows / macOS / Linux 三端一致；如后续改用 Tauri 需安装 Rust 工具链）。
- 手机端：Kotlin + Jetpack Compose（Material3），minSdk 26。
- 通信：明文 HTTP + 可选 Token（局域网内使用；如需公网请自行加反向代理与 TLS）。
