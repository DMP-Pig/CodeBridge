# 手机端疑难排查：无法安装任何应用（INSTALL_FAILED_VERIFICATION_FAILURE）

## 现象
- 手机（示例机型 ZRSX K118，Android 10，高通 sdm450）无法安装任何第三方 APK，
  包括 adb install / pm install / 手动安装器，均返回 `INSTALL_FAILED_VERIFICATION_FAILURE`。
- 手机无应用商店、无浏览器，第三方应用仅预装少量（微信/QQ音乐/讯飞输入法等）。
- 关闭系统验证开关（`package_verifier_enable`、`verifier_verify_adb_installs`、
  `pm_install_verify`、`security_scan_install_enable`）并重启后仍失败。

## 根因（已通过反编译系统框架确认）
定制 ROM 修改了 `PackageManagerService`（services.jar 中的 `InstallParams.handleStartCopy`）：

- 当系统属性 `persist.sys.whitelistapp` 为字符串 `"true"` 时，
  PMS 会调用 `isWhiteListApp(packageName)`：
  - 逐行读取 `/system/etc/whitelistapp.conf`，与包名做**精确字符串匹配**（不支持通配符）；
  - 不在白名单内的包，直接返回错误码 `-22`（即 INSTALL_FAILED_VERIFICATION_FAILURE）；
  - 文件读取失败/文件不存在也按“不在白名单”处理（返回 false）。
- 该 ROM 出厂把 `persist.sys.whitelistapp` 置为 `true`，所以一切安装都被拒绝。

## 修复（无需刷机、无需 root）
`powershell
adb shell setprop persist.sys.whitelistapp false
`
- `persist.*` 属性会持久化到 `/data/property`，重启后仍为 `false`；
- 已验证系统脚本/应用中没有在开机时把它改回 `true` 的逻辑；
- 改完后任意非白名单 APK 均可正常安装。

## 验证
- `adb install -r -t xxx.apk` → Success
- 建议同时确认：`adb shell getprop persist.sys.whitelistapp` 输出为 `false`。

## 附：手机端连不上 PC（Cleartext HTTP traffic ... not permitted）
- 原因：Android 10+（targetSdk>=28）默认禁止明文 HTTP；本项目手机端与 PC 端走局域网 HTTP。
- 修复：`AndroidManifest.xml` 的 `<application>` 增加 `android:usesCleartextTraffic="true"`。
